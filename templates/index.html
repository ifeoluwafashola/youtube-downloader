    Help
    
      
    
    
  
    
    
    
      
    
        
    Getting started
    
        
      
          
    1. Paste a YouTube link in the box at the top and click Inspect. The title and details appear so you can check it is the right thing.
      2. 
          
    2. Choose Video and a quality, or Audio only and a format (MP3 for listening, WAV for editing, Original for the smallest file).
      3. 
          
    3. Click Add to queue. Downloads run one after another; you can keep adding.
      4. 
        
    
      
    
      
    
        
    Playlists
    
        
    Paste a playlist link and Inspect lists every video. Download All, a Range such as 5–20, or Pick individual ones. Each playlist gets its own folder. Running the same playlist again only fetches what is new.
    
        
    A link that contains both a video and a playlist (watch?v=…&list=…) asks which one you mean.
    
      
    
      
    
        
    Part of a video
    
        
    Tick Clip and enter from/to times such as 12:00 and 15:00. Only that section is downloaded. Cuts land on the nearest keyframe, so allow a second or two either side.
    
      
    
      
    
        
    Several links at once
    
        
    Open Add several links at once, paste one link per line, choose the settings once, and add them all.
    
      
    
      
    
        
    Where files go
    
        
    Into . Change it under Settings. Each finished item shows its files with Play (in this page), Open (your media player) and Show in folder.
    
        
    MKV files cannot play in the page - use Open. Prefer MP4 unless a player struggles with 4K.
    
      
    
      
    
        
    History
    
        
    The list is kept across restarts. If you delete a file from disk it is marked here and Download again fetches it once more. Clear history only clears this list - files are never deleted.
    
      
    
      
    
        
    When downloads stop working
    
        
    YouTube changes things every few weeks. If downloads suddenly fail (403, "not a bot", "format not available"), click Update at the top, then Restart now. A blue banner appears here when an update is available.
    
      
    
      
    
        
    Age-restricted or members-only videos
    
        
    These need your YouTube login. Start the console with Start.bat --cookies-from-browser firefox (Chrome and Edge do not allow this on Windows). See TROUBLESHOOTING.md in the program folder for details.
